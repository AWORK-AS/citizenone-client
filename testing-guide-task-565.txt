TESTING GUIDE — Task-565: Billing Module
=========================================


PREREQUISITES
-------------
- Logged in as a user at a company with Employment Services sector
  (industry.system_name === 'employment_services')
- At least one active Employment agreement, case type, and case with a citizen assigned
- User has the Billing permission enabled


1. BILLING RULES (Settings)
----------------------------
Navigate to: Settings > Billing Rules (/settings/employment-billing-rules)

Create — Weekly
  1. Click "Add new billing rule"
  2. Set: Name = "Standard ugentlig", Pricing type = Weekly pricing,
     Weekly rate = 5000, Customer no. = 10042, Product no. = P-001
  3. Save -> should redirect to list, success alert shown
  4. Rule appears in table with correct pricing type badge and rate

Create — Hourly
  1. Create another rule, Pricing type = Hourly pricing, Hourly rate = 200
  2. Save -> verify hourly rate shows in the rate column

Create — Bonus
  1. Create another rule, Pricing type = Bonus-based pricing,
     Bonus amount = 5000, Trigger condition = 3 months
  2. Save -> verify bonus amount + months shown in rate column (e.g. 5000 (3 mdr.))

Edit
  1. Click Edit on any rule -> fields load correctly
     (weekly rule shows rate field, not hourly_rate)
  2. Change name -> Update -> success alert, list reflects change

Delete
  1. Click Delete -> confirmation dialog appears
  2. Confirm -> rule removed from list, success alert shown


2. STATUS TYPE — BILLING RULE LINKING
--------------------------------------
Navigate to: Settings > Status Types (/settings/employment-status-types)

  1. Create or edit a status type
  2. "Billing rule" dropdown should be populated with active billing rules
  3. Select a weekly billing rule -> Save
  4. Edit the status type again -> billing rule dropdown shows the saved selection


3. BILLING WEEKS (per Case)
----------------------------
Navigate to: Citizen > Employment cases tab

View weeks
  1. Find a case with a start date -> click the billing weeks button
  2. Slide-over opens showing weeks from case start date to today
  3. Each row shows: ISO week number, date range, Billable/Excluded badge

Exclude a week
  1. Click "Exclude week" on a billable week
  2. An inline text input and Confirm button appear
  3. Type a reason (e.g. "Borger indlagt") -> press Enter or click Confirm
  4. Week turns red, shows "Excluded" badge,
     reason text appears in italics below the date range
  5. Footer counter updates (excluded weeks count increases)

Exclude without reason
  1. Click "Exclude week" on another week
  2. Leave the reason input empty -> Confirm
  3. Week is excluded, no reason text shown (blank is fine)

Cancel exclusion
  1. Click "Exclude week" -> input appears -> click the X button or press Escape
  2. Input dismisses, week stays billable

Re-include a week
  1. Click "Include week" on an excluded week
  2. Week immediately turns green, reason text disappears, counter updates


4. BILLING EXTRACTION
----------------------
Navigate to: Billing > Billing (/billing/employment)

Generate
  1. Set From date and To date covering a period where active cases exist
  2. Click Generate
  3. Table appears with rows: citizen name, CPR, agreement, period,
     price/week, weeks, bonus, total, customer no., product no., invoiced status
  4. Summary bar shows invoiced / not-invoiced counts

Empty state
  1. Pick a date range with no cases -> "No billing data found" message shown

Mark as invoiced
  1. Select one or more not-invoiced rows using checkboxes
  2. "Mark selected as invoiced" button appears with count
  3. Click it -> success alert, selected rows now show green "Invoiced" badge
     and are greyed out
  4. Checkboxes disappear on invoiced rows
  5. Re-run the same period -> invoiced rows still show as invoiced (amounts frozen)

Select all
  1. With data loaded, click "Select all" checkbox in the summary bar
  2. All non-invoiced rows are selected
  3. Uncheck -> all deselected

Export to e-conomic (CSV)
  1. With extraction data loaded, click "Export to e-conomic (CSV)"
  2. File billing-{from_date}_{to_date}.csv downloads
  3. Open in Excel or text editor — verify columns:
     CustomerNumber, ProductNumber, Description, Quantity,
     UnitPrice, Date, YourReference
  4. Description format: Citizen Name — Agreement Name (DD/MM/YYYY-DD/MM/YYYY)
  5. All rows present (including already-invoiced ones)


5. REVENUE REPORT
------------------
Navigate to: Reports > Revenue report (/reports/employment-revenue)

  1. Set date range -> click Generate
  2. Summary cards show: Total revenue, Weekly billing, Hourly billing, Bonuses
  3. Table shows one row per consultant with citizen count and billing breakdown
  4. Totals row at bottom matches sum of all consultant rows
  5. "Unassigned" row appears if any cases have no assigned user


6. SECTOR GUARD
----------------
  1. Log in as a user at a non-employment company
  2. Verify Billing and Revenue report links do not appear in the sidebar
  3. Directly navigate to /billing/employment -> redirected to /overview
  4. Directly navigate to /reports/employment-revenue -> redirected to /overview
  5. Directly navigate to /settings/employment-billing-rules
     -> redirected away from employment settings


7. I18N SPOT-CHECK
-------------------
Switch the app language to Danish and verify:
  - Billing extraction page labels are in Danish
  - "Eksporter til e-conomic (CSV)" button label shows correctly
  - Billing weeks slide-over labels including reason placeholder (fx. Borger indlagt)
  - Billing rules form labels and pricing type options are in Danish
