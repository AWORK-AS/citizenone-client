TASK-632 TESTING GUIDE
Protocol - Scheduling & Citizen Access
=======================================


PREREQUISITES
-------------
- A company with industry.system_name = "employment_services" (for citizen check-in/out)
- A staff account with the Attendance page enabled
- A citizen account linked to that company


=======================================================
PART 1: CUSTOM SCHEDULING (STAFF)
=======================================================

TEST 1 - Non-recurring (baseline)
----------------------------------
1. Go to /protocols/new
2. Fill name, start/end dates, select citizens
3. Leave Recurring unchecked, toggle Exclude weekends if desired
4. Save
EXPECT: Success alert, redirect to /protocols


TEST 2 - Preset recurrence
----------------------------
1. New protocol > check Recurring
2. Set Repeat = "Every second week", set Recurring until
3. Save
EXPECT: Protocol created, no error


TEST 3 - Custom weekly ("every 2nd Tuesday")  [VERIFIED]
---------------------------------------------------------
1. New protocol > check Recurring > Repeat = Custom
2. Frequency = Weekly, Every = 2, Week on = Tuesday
3. Set Recurring until > Save
EXPECT: recurring_rules shows frequency=weekly, every=2, weekly_on=[2]


TEST 4 - Custom monthly (1st and 15th)
---------------------------------------
1. New protocol > check Recurring > Repeat = Custom
2. Frequency = Monthly, Every = 1
3. Leave "On the" unchecked > On days = select 1 and 15
4. Save
EXPECT: Occurrences on the 1st and 15th of each month


TEST 5 - Custom monthly ("first Monday")
-----------------------------------------
1. Same as Test 4 but check "On the"
2. Sequence = First, Day = Monday
3. Save
EXPECT: Occurrences on the first Monday of each month


TEST 6 - Custom yearly
-----------------------
1. Repeat = Custom, Frequency = Yearly, Every = 1
2. In months = June, leave "On the" unchecked
3. Save
EXPECT: Yearly occurrence in June


TEST 7 - Validation
--------------------
- Check Recurring but leave Recurring until empty > Save
  EXPECT: Required error on Recurring until field

- Custom + Weekly with no days selected > Save
  EXPECT: Required error on Week on field


=======================================================
PART 2: CITIZEN CHECK-IN / CHECK-OUT
=======================================================

SETUP: Ensure the citizen has at least one CitizenProtocol entry for
today, created via a staff protocol covering today's date.


TEST 8 - Nav gating (employment services only)
-----------------------------------------------
- Log in as citizen of an employment-services company
  EXPECT: "Protocols" appears in the sidebar

- Log in as citizen of a non-employment-services company
  EXPECT: "Protocols" is NOT in the sidebar


TEST 9 - Citizen protocols page
---------------------------------
1. Log in as citizen > navigate to /citizen/protocols
EXPECT:
  - Today's protocol entries listed as cards
  - Each card shows: protocol name, date, status badge
  - null status    > "Check in" button shown
  - attended status > "Check out" button shown
  - absent status   > static "Absent" label, no button


TEST 10 - Check in
-------------------
1. Click "Check in" on a null-status entry
EXPECT:
  - Button disables while loading
  - Badge updates to "Attended"
  - Success alert appears
  - Reload page > status persists as attended


TEST 11 - Check out
--------------------
1. Click "Check out" on an attended entry
EXPECT:
  - Badge updates to "Absent"
  - Success alert appears
  - Reload page > status persists as absent


TEST 12 - Error cases
----------------------
- Double check-in on already-attended entry
  EXPECT: Error toast with BE message (already_checked_in)

- Check out without being checked in
  EXPECT: Error toast with BE message (not_checked_in)
