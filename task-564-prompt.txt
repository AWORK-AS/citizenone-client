We are working on task-564 (F-04 — Configurable status model) in a Vue 3 / Nuxt client app
for an Employment Services sector product.

The task is mostly complete but one piece is broken: the History button on the citizen
employment cases page opens nothing.

--- WHAT IS BUILT ---

All these files exist and are implemented:

- components/modules/user/employment/case/status-history-modal.vue
  Props: isModalOpen (Boolean), selectedCase (Object)
  Emits: close, statusUpdated
  Fetches GET /employment/cases/{uuid}/status-history on open
  Posts  POST /employment/cases/{uuid}/status-history to add entries

- components/api/user/EmploymentService.ts
  getCaseStatusHistory(caseUuid)         -> GET /user/employment/cases/{uuid}/status-history
  saveCaseStatusHistory(caseUuid, params) -> POST /user/employment/cases/{uuid}/status-history

- pages/citizens/[uuid]/employment-cases.vue
  Has a History button per row (line 89) that calls openStatusHistory(employmentCase)
  openStatusHistory sets state.modal.isHistoryOpen = true and state.selectedCase = employmentCase
  closeHistoryModal sets isHistoryOpen = false and clears selectedCase
  state.modal.isHistoryOpen and state.selectedCase are both declared in reactive state

--- THE BUG ---

The <ModulesUserEmploymentCaseStatusHistoryModal> component is never rendered in the template.
The other modals are rendered around lines 119-134 of employment-cases.vue:

  <ModulesUserEmploymentCaseModalNew ... />
  <ModulesUserEmploymentCaseModalEdit ... />
  <ModulesUserEmploymentCaseBillingWeeksSlideOver ... />
  <ModulesUserMyCalendarModalSubscribe ... />
  <DialogConfirmation ... />

The status history modal needs to be added to this block. Its wiring should be:

  <ModulesUserEmploymentCaseStatusHistoryModal
      :isModalOpen="state.modal.isHistoryOpen"
      :selectedCase="state.selectedCase"
      @close="closeHistoryModal"
      @statusUpdated="fetchCases" />
